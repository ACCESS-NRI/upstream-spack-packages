# ACCESS-NRI fork of the upstream spack-packages repository

This repository is a fork of the upstream [spack-packages](https://github.com/spack/spack-packages) repository. The `access-nri` branch only contains this `README.md` file.

This repository's `access/*` branches are maintained by ACCESS-NRI and allows backporting of bug fixes or important features.

A regular user on Gadi does not need to clone this repository. Advanced users should refer to [ACCESS-NRI's Spack configuration](https://github.com/ACCESS-NRI/spack-config).
